三、深度配置教程：从入门到精通

1. 代理服务器配置

Shadowrocket智友提供两种主要的配置方式：手动配置和订阅配置。对于初学者，推荐使用订阅方式，因为它更加简便快捷。

手动配置详细步骤： - 打开应用，点击底部导航栏的"配置"选项 - 选择"配置列表"，点击右上角的"+"按钮 - 选择"手动"配置方式 - 依次填写代理名称（自定义）、类型（如Shadowsocks、Vmess等） - 根据所选协议类型填写相应的服务器信息： - 对于Shadowsocks：需要填写服务器地址、端口、加密方法和密码 - 对于Vmess：需要填写地址、端口、用户ID、额外ID、加密方式等 - 完成填写后点击"保存"

订阅配置方法： - 在配置页面选择"订阅" - 点击"添加订阅" - 输入服务商提供的订阅链接 - 设置自动更新频率（建议选择24小时） - 点击"完成"后，应用会自动获取并更新节点列表

黑名单管理： - 屏蔽广告域名 - 阻止恶意网站 - 限制特定应用的网络访问

FAQ

V2Ray 的 Reality 功能是什么？
Reality 是 V2Ray 新增的伪装技术，可替代传统 TLS。它无需真实证书，通过公钥验证机制实现端到端加密。相比 Trojan 的 HTTPS 伪装方式，Reality 更轻量、安全且配置更简洁。
如何为 Vmess 节点生成安全的 UUID？
UUID 应使用标准的 128 位格式，可使用系统命令如 `uuidgen` 或在线 UUID 生成器生成随机、唯一的 ID；不要使用默认或弱随机值，定期更换以降低被滥用或泄露的风险。
Hiddify Next 是否兼容 Clash 或 V2Ray 配置文件？
Hiddify Next 支持部分 Clash 与 Xray 订阅格式，但建议使用其官方订阅格式以获得完整兼容。若订阅转换异常，可使用 Hiddify 提供的在线转换工具重新生成配置文件导入。
Clash 的 Rule Provider 有什么作用？
Rule Provider 是 Clash 的规则分发机制。用户可以订阅不同的规则集，比如广告拦截、社交媒体、流媒体等，实现按需加载。它让配置文件更加简洁、动态更新，并支持多源规则管理。
V2Ray 配置文件中 inbound 和 outbound 有什么区别？
在 V2Ray 中，inbound 表示流量进入方式（如本地代理端口），outbound 表示流量出口方式（如 VMess、Trojan 等协议）。通过灵活组合两者，可以实现局域网共享、分流及中继等功能。
V2Ray 策略组如何根据节点延迟自动选择？
策略组会根据节点延迟和丢包率自动选择最优节点。结合路由规则可保证国内流量直连，海外流量走最佳节点，提高访问速度和连接稳定性，优化整体网络体验。
Nekoray 支持 Trojan 吗？
支持。Nekoray 基于 sing-box 核心，能兼容 Trojan、Vmess、Vless、Hysteria2 等多种协议。用户可在同一界面中管理和切换不同类型节点，非常方便。
Hiddify Next 如何实现用户流量分配？
管理员可为每个用户设置带宽和流量配额。超出限制时可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
V2Ray 的 WebSocket 传输与 TCP 有何区别？
WebSocket 通过 HTTP 封装 TCP 流量，适合伪装成正常网页请求，增加隐蔽性。相比原生 TCP，可更好地绕过封锁和 DPI 检测，但略增加协议开销。
如何在 Sing-box 中设置多个 outbound 实现策略路由？
在 sing-box 的配置中定义多个 outbound 对象并为 routing 模块配置 rules，将不同目的地或应用流量指向对应 outbound，从而实现分流、负载均衡或故障转移等复杂路由策略。
